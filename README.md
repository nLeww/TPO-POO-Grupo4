Instrucciones:

El programa cuenta con la interfaz de usuario "Administrador" Con la que se puede:

1. Mirar los reclamos y asignar empleados a los mismos.
2. Ver las expensas de cada lote, junto a las deudas y los detalles de las mismas
3. Ver todas las visitas (vigentes o abiertas)
4. Generar y ver las ordenes de mantenimiento

La navegacion por la interfaz se simplifico. Al momento de entrar, se ingresa con un usuario anteriormente seteado
con nombre "Ramon" y contrasena "12345". Al entrar aparecera un menu de opciones con las siguientes opciones:

1. Ver Visitas
2. Ver Mantenimiento
3. Ver Expensas
4. Ver Reclamos
---------------

Si se ingresa a "Ver Visitas", aparecera el siguiente menu:

1. Ver visitas vigentes
2. Ver visitas pendientes
3. Buscar visita por documento

Para buscar por documento, solo se debe ingresar el numero y se hara una busqueda en ambos archivos de visitas

----------------
Si se ingresa a "Mantenimiento", aparecera el siguiente menu:

1. Ver todos los dispositivos
2. Generar orden de Mantenimiento

Para generar ordenes, solo hace falta dar los datos del empleado

----------------

Si se ingresa a "Ver expensas", aparecera el siguiente menu:

1. Consultar deuda de lote
2. Mostrar detalles de deuda

Ambas funciones son para visualizar que lotes tienen deuda e informacion 

----------------

Si se ingresa a "Ver Reclamos", aparecera el siguiente menu:

1. Ver historial de reclamos
2. Asignar responsable

----------------
